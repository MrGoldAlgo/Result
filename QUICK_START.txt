MR GOLD TRADING PORTAL — V3 FREE EDITION
=========================================

GOAL
----
$0/month hobby/personal setup:
MT5 -> MR_Gold_MT5_Sync_Free_V3 EA -> Render Free Web Service -> Supabase Free database

You do NOT need MetaApi and you do NOT enter your MT5 master/investor password into this website.
The MT5 terminal you already run sends read-only performance data to the website.

PART A — CREATE THE FREE DATABASE (SUPABASE)
--------------------------------------------
1. Create a free account at https://supabase.com
2. Create a new Free project.
3. Open SQL Editor -> New query.
4. Open the included file: supabase_schema.sql
5. Copy all of it into SQL Editor and click Run.
6. Open Project Settings / Connect / API Keys.
7. Copy these TWO values for later:
   - Project URL, similar to: https://abcdef.supabase.co
   - Secret key, starting with: sb_secret_
   IMPORTANT: never put the secret key in browser code, GitHub, or the MT5 EA.

PART B — PUT THE WEBSITE ON GITHUB
----------------------------------
8. Create a new PRIVATE GitHub repository, for example:
   mr-gold-trading-free
9. Upload the CONTENTS of this V3 Free folder to that repository.
10. Do not upload any real passwords/keys. The included .env.example contains placeholders only.

PART C — DEPLOY THE WEBSITE ON RENDER FREE
------------------------------------------
11. Create a free Render account at https://render.com
12. New -> Blueprint.
13. Connect the private GitHub repository you created.
14. Render detects render.yaml. Apply the Blueprint.
15. When Render asks for environment variables, enter:

    ADMIN_TOKEN
    = make your own long private password

    SUPABASE_URL
    = the Supabase Project URL from Step 7

    SUPABASE_SECRET_KEY
    = the sb_secret_... key from Step 7

16. Wait for the deploy to finish.
17. Render gives you an address similar to:
    https://mr-gold-trading-free.onrender.com
18. Open:
    https://YOUR-SITE.onrender.com/health
    It should show:
    "ok": true
    "supabase_configured": true

PART D — CREATE YOUR TRACKED MT5 ACCOUNT
----------------------------------------
19. Open:
    https://YOUR-SITE.onrender.com/admin
20. Enter the ADMIN_TOKEN from Render.
21. Click Load accounts to verify admin access.
22. Under Create tracked MT5 account enter, for example:

    Display name: Vantage Live 100K
    Public slug: vantage-main

23. Click Create account + API key.
24. COPY the generated API key immediately. It looks like:
    mg_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Your public result page is now:
    https://YOUR-SITE.onrender.com/p/vantage-main

PART E — INSTALL THE FREE MT5 SYNC EA
-------------------------------------
25. Open MetaTrader 5 -> File -> Open Data Folder.
26. Go to MQL5 -> Experts.
27. Copy MR_Gold_MT5_Sync_Free_V3.mq5 into that folder.
28. Open MetaEditor and compile it.
29. Back in MT5, attach ONE copy of MR_Gold_MT5_Sync_Free_V3 to any chart on that account.
30. Use inputs:

    InpWebsiteUrl = https://YOUR-SITE.onrender.com
    InpApiKey = mg_xxxxxxxxxxxxxxxxx
    InpSyncEverySeconds = 300
    InpInitialHistoryDays = 730
    InpRecentHistoryDays = 14
    InpAutoDetectMrGoldV158 = true
    InpMrGoldBaseMagic = 1517

31. MT5 -> Tools -> Options -> Expert Advisors.
32. Tick: Allow WebRequest for listed URL.
33. Add EXACTLY:
    https://YOUR-SITE.onrender.com
34. Click OK and make sure Algo Trading is enabled.

PART F — VERIFY
---------------
35. Check MT5 Experts tab. You should see the Free Sync EA start message and no HTTP errors.
36. Open the public result page again.
37. Balance/equity and trades should appear after sync.
38. Your V1.58 Unique IDs are decoded automatically:

    Base Magic 1517
    1517001 -> Unique ID 1
    1517002 -> Unique ID 2
    1517015 -> Unique ID 15

The EA also reads V1.58 comments such as:
    PD|4450.00|B|1|SLP=1000.0
    AS|4420.00|S|15|SLP=1000.0

FREE-TIER NOTES
---------------
- Render Free can spin down after 15 minutes without inbound traffic. The default 5-minute MT5 sync normally keeps it active while MT5 is running.
- If it does sleep, the EA uses a long HTTP timeout so the first request has time to wake it.
- Supabase Free currently provides 500 MB database capacity.
- The Free plan is suitable for personal/hobby use. It does not include production-grade backups/availability.
- If MT5 is stopped, no new trading data can be uploaded until it is running again.

SECURITY
--------
- Never upload your Supabase secret key to GitHub.
- Never put the Supabase secret key into MT5.
- MT5 only receives the per-account mg_ API key generated by your website.
- The website does not need your MT5 master password or investor password.
